1. Descripción de la aplicación

Aplicación web que se abre con doble clic en ABRIR.html y funciona en el navegador sin internet, sin instalaciones, sin cuentas y sin comandos. Tiene 12 módulos: Descriptiva, Conteo y probabilidad, Binomial, Hipergeométrica, Poisson, Uniforme continua, Normal, Gamma, Exponencial, Ji cuadrada, Lognormal y Teorema del límite central. Cada módulo muestra definición, parámetros, supuestos, media y varianza; campos con instrucciones; botones Calcular, Limpiar, Cargar ejemplo e Importar archivo; y como resultado una tabla, el procedimiento paso a paso, una gráfica y la interpretación. Los conceptos de variable aleatoria y esperanza se explican en la página de inicio y en la definición de cada distribución (qué cuenta o mide X y E[X]).

Herramientas y bibliotecas

HTML, CSS y JavaScript estándar. No se usan bibliotecas externas: los cálculos están programados en estadistica.js. Los métodos numéricos usados son:

  • ln Γ(x): aproximación de Lanczos (g = 7, 9 coeficientes), error relativo ≈ 10⁻¹⁵.
  • Gamma incompleta regularizada P(a, x): serie de potencias si x < a + 1 y fracción continua (algoritmo de Lentz) en otro caso, con tolerancia 10⁻¹⁶. Con ella se calculan las acumuladas Gamma P(α, x/θ), Ji cuadrada P(ν/2, x/2), Poisson P(X ≤ k) = 1 − P(k + 1, λ) y Normal Φ(z) = ½[1 + P(½, z²/2)] para z ≥ 0 (por simetría para z < 0). La lognormal usa Φ((ln x − μ)/σ).
  • Combinaciones: enteros exactos (BigInt) para mostrar C(n, r) completo; en probabilidades binomiales e hipergeométricas se usan logaritmos para evitar desbordes.
  • Para verificar (no forma parte de la aplicación) se usó la biblioteca mpmath de Python con mp.dps = 30 (30 dígitos): ncdf(z) para Φ y gammainc(a, 0, x, regularized=True) para la gamma incompleta.

2. Situaciones aplicadas a Ingeniería en Sistemas

Situación 1 — Análisis descriptivo: tiempos de respuesta de una API

Datos: simulados. 12 tiempos de respuesta (ms) de un endpoint REST: 120, 135, 128, 140, 150, 128, 132, 145, 138, 128, 160, 126.

Modelo y justificación: estadística descriptiva para datos sin agrupar, porque es una sola variable cuantitativa con pocos datos. Se consideran una muestra de todas las peticiones que recibe el servidor, por lo que la varianza adecuada es la muestral (divide entre n − 1).

Resultado: x̄ = 135.83 ms, mediana = 133.5 ms, moda = 128 ms, rango = 40 ms, s = 11.43 ms (σ = 10.95 ms si fuera población). Decisión: el servicio responde típicamente en ≈ 136 ms con poca variación; el valor de 160 ms está a más de dos desviaciones estándar de la media (2s ≈ 22.9 ms) y conviene revisarlo como posible atípico.

Situación 2 — Probabilidad: tickets de la mesa de ayuda

Datos: simulados. Se supone un promedio histórico de 6 tickets por hora.

Modelo y justificación: Poisson, porque X cuenta eventos en un intervalo de tiempo, los tickets llegan de forma independiente, a una tasa promedio estable, y no llegan dos al mismo instante. No es binomial porque no hay un número fijo de ensayos. Para un turno de 30 minutos se ajusta λ = 6 × 30/60 = 3.

Resultado: P(X = 2) = 0.2240, P(X ≤ 2) = 0.4232 y P(X ≥ 2) = 0.8009. Decisión: en 8 de cada 10 turnos de media hora llegan al menos 2 tickets, por lo que se justifica tener al menos un técnico dedicado en cada turno.

Los demás ejemplos precargados también son casos de Sistemas: pérdida de paquetes (binomial), licencias defectuosas (hipergeométrica), tiempo de descarga (uniforme), tiempo de compilación (normal), tiempo para atender solicitudes (gamma), tiempo entre fallas de un servidor (exponencial), prueba de un generador de números aleatorios (ji cuadrada), tamaño de archivos subidos (lognormal) y tiempo medio de respuesta (TLC).

3. Cálculos verificados a mano

A) Descriptiva (prueba P1). Σx = 1630, n = 12 → x̄ = 1630/12 = 135.8333.

Σx² = 14400 + 18225 + 3(16384) + 19600 + 22500 + 17424 + 21025 + 19044 + 25600 + 15876 = 222 846.

Σ(x − x̄)² = Σx² − (Σx)²/n = 222 846 − 1630²/12 = 222 846 − 221 408.3333 = 1437.6667.

σ² = 1437.6667/12 = 119.8056 (σ = 10.9456) · s² = 1437.6667/11 = 130.6970 (s = 11.4323). Coincide con la aplicación.

Datos ordenados: 120, 126, 128, 128, 128, 132, 135, 138, 140, 145, 150, 160 → mediana = (132 + 135)/2 = 133.5; moda = 128 (3 veces).

B) Binomial (prueba P3), n = 10, p = 0.1:

P(X = 0) = 0.9¹⁰ = 0.348678 · P(X = 1) = 10(0.1)(0.9⁹) = 0.387420 · P(X = 2) = C(10,2)(0.1²)(0.9⁸) = 45(0.01)(0.430467) = 0.193710.

P(X ≤ 2) = 0.348678 + 0.387420 + 0.193710 = 0.929809 · P(X ≥ 2) = 1 − (0.348678 + 0.387420) = 0.263901. Coincide con la tabla A.1 (0.9298).

C) Bayes (prueba P2): P(E) = 0.5(0.01) + 0.3(0.02) + 0.2(0.04) = 0.005 + 0.006 + 0.008 = 0.019; P(A₃|E) = 0.008/0.019 = 0.421053; P(A₁|E) = 0.005/0.019 = 0.263158; P(A₂|E) = 0.006/0.019 = 0.315789.

D) Normal (prueba P7): z(45) = (45 − 50)/5 = −1.00 y z(58) = (58 − 50)/5 = 1.60. De la tabla A.3: Φ(−1.00) = 0.1587 y Φ(1.60) = 0.9452, por lo que P(X ≥ 58) = 1 − 0.9452 = 0.0548 y P(45 ≤ X ≤ 58) = 0.9452 − 0.1587 = 0.7865. La aplicación da 0.158655, 0.054799 y 0.786545.

4. Pruebas documentadas

Se documentan 15 pruebas: una por cada uno de los 12 módulos y 3 de entradas inválidas (el mínimo pedido es nueve). La prueba de Descriptiva compara la varianza poblacional con la muestral, y la de Conteo y probabilidad es compuesta (combinaciones, unión, condicional y Bayes).

Tolerancia: los resultados esperados están redondeados a 6 decimales, por lo que se acepta una diferencia absoluta |obtenido − esperado| ≤ 0.000001. Los valores tomados de tablas impresas de 4 decimales (ji cuadrada) se comparan con tolerancia 0.0001. Las pruebas de entradas inválidas pasan si la aplicación muestra un mensaje con el texto indicado y sigue funcionando.

Resultado obtenido: la columna "Obtenido" de las tablas siguientes fue generada ejecutando el código de la aplicación al crear este documento. Las mismas pruebas se pueden volver a ejecutar en ABRIR.html → Comprobación.

5. Conclusiones

  • La aplicación calcula correctamente las medidas descriptivas, las reglas de probabilidad, las 9 distribuciones y el teorema del límite central; las 15 pruebas coinciden con los valores de referencia dentro de la tolerancia.
  • Elegir el modelo correcto depende de los supuestos: contar éxitos en n ensayos independientes (binomial), muestrear sin reemplazo (hipergeométrica), contar eventos en un intervalo (Poisson, ajustando λ al intervalo) o medir tiempos (exponencial y gamma).
  • Es importante distinguir σ (desviación estándar) de σ² (varianza), la tasa λ del tiempo promedio 1/λ y los parámetros de ln X en la lognormal; la aplicación permite ingresar cada uno de forma explícita para evitar errores.
  • El teorema del límite central muestra que el promedio de muchas mediciones varía mucho menos (σ/√n) que una medición individual.
